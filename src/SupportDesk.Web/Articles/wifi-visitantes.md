# Wi-Fi para visitantes

A rede sem fios da empresa é só para equipamentos da empresa. Os visitantes usam a rede de convidados, separada da rede interna.

## Como pedir acesso para um visitante

1. Pede o acesso com um dia de antecedência, com o nome do visitante e a data da visita.
2. O técnico envia-te um código válido só nesse dia.
3. O visitante liga-se à rede de convidados e escreve o código na página que se abre no browser.

## Problemas frequentes

- A página do código não abre: o visitante deve abrir um site qualquer no browser para a página aparecer.
- O código foi recusado: confirma a data. Os códigos expiram à meia-noite.
- A internet é lenta: a rede de convidados tem uma velocidade limitada e não serve para chamadas de vídeo longas.

## Quando abrir um pedido

Abre um pedido para cada visita, com o nome do visitante, a data e quantos equipamentos vai ligar.
