# Pedir a instalação de um programa

Os computadores da empresa não deixam instalar programas sem um técnico. Assim, evitam-se programas sem licença e software malicioso.

## Antes de pedir

- Confirma se o programa já existe no portal de software da empresa: os programas aprovados instalam-se lá sem pedido.
- Vê se há uma versão web que sirva para o que precisas.

## Como pedir

1. Abre um pedido com o nome do programa, a versão e o site oficial de onde se descarrega.
2. Explica para que precisas dele e durante quanto tempo.
3. Se o programa for pago, indica quem aprova a despesa.

## Depois do pedido

O técnico confirma a licença e a segurança do programa e marca contigo uma hora para a instalação. Um programa sem licença ou sem fonte oficial não é instalado.
